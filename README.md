## The word

**CHATGBT**

The single word grandma would text about AI: her typo of ChatGPT. Warm,
a little baffled, instantly readable, and tied to AI in one word — no
sentence, no explanation, just the way she would actually type it.

## How it works

`main.ts` writes exactly that one word to `/output/entry.txt` (7 bytes,
no trailing newline), after checking it passes the gate: 1–30 characters
of UTF-8 text, not only whitespace.

Run it with Node 22+:

```sh
node main.ts
```
